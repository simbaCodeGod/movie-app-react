## About The Project

This project is a single-page application to browse movie information. It utilizes The Movie Database (TMDB) API to fetch and display movie data.

## Features

- **Browse Movies:** View a list of popular/trending movies.
- **Search Functionality:** Find specific movies by title.
- **Movie Details:** Click on a movie to see more information (e.g., plot, cast, ratings).
